# Feature Sleuth Web App 🎮

A React-based web application for playing Feature Sleuth, the educational guessing game.

## Features

✨ **Fully Interactive UI**
- Beautiful, responsive design that works on desktop and mobile
- Smooth animations and transitions
- Intuitive game flow

🎡 **Animated Spinning Wheel**
- SVG-based spinning wheel with smooth animations
- Weighted probability visualization
- Exciting 2-second spin animation

📊 **Post-Game Analysis**
- Detailed score breakdown
- Performance metrics (efficiency, optimal turns)
- Gameplay suggestions for improvement
- Complete turn-by-turn history

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Visit `http://localhost:5173` to play!
